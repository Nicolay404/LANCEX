# Bitácoras de las IA

Cada rol mantiene una bitácora propia para evitar conflictos de edición:

- `architect.md`
- `backend.md`
- `database.md`
- `frontend.md`
- `security.md`

La fecha/hora real debe obtenerse con el comando documentado en `PROTOCOLO-DE-IA.md`. No se inventan marcas de tiempo. Las bitácoras deben ser breves, auditables y enlazadas a issues/PRs. No incluyen secretos, tokens ni datos privados.

Se registra al menos el inicio y final de tareas significativas, resultados reales de pruebas, decisiones, bloqueos y handoffs. Una prueba que no se ejecutó se etiqueta como pendiente/propuesta.
